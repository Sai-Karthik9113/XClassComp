# Counter App

This is a simple Counter App built using React.js as part of a course project. It allows users to increment and decrement a counter value using buttons.

## Features
- Increment and Decrement buttons to modify the count
- Real-time display of the current count
- Simple UI with no additional pages

## Installation
1. Clone the repository:
   ```
   git clone https://github.com/Sai-Karthik9113/XClassComp.git
   ```

2. Navigate to the project directory:
   ```
   cd counter-app
   ```

3. Install dependencies:
   ```
   npm install
   ```

4. Run the app:
   ```
   npm start
   ```

The app will be available at `http://localhost:3000` in your browser.

## Technologies Used

- React.js (Class-based components)
